# Web Sikopin

Website landing page Sikopin menggunakan PHP Native dan Tailwind CSS.

## Tech Stack

- PHP Native
- Tailwind CSS 3
- PostCSS
- Autoprefixer

## Instalasi

```bash
# Clone repository
git clone https://github.com/username/web-sikopin.git
cd web-sikopin

# Install dependencies
npm install

# Build CSS
npm run build
```

## Development

```bash
# Jalankan Tailwind dalam mode watch
npm run dev
```

## Struktur Project

```
web-sikopin/
├── assets/          # Gambar dan file statis
├── dist/            # Output build CSS
├── modul/           # Modul PHP
├── src/             # Source CSS (Tailwind)
├── index.html       # Halaman utama
├── style.css        # Custom CSS
└── tailwind.config.js
```

## Build

```bash
# Build untuk production
npm run build
```
